## Why

Pianoles gives learners a direct connection between written music, keyboard positions, and sound through a browser-based course.

## What Changes

- Add a numbered and shareable 24-lesson curriculum.
- Add playable notation exercises, feedback, and instrument input.
- Remember progress locally and publish the app through GitHub Pages.

## Capabilities

### New Capabilities

- `lesson-catalog`: Progressive lessons, notation, and navigation.
- `practice`: Demonstration, guided and timed exercises, and hand and passage controls.
- `instrument-input`: Browser keyboard, touch, and compatible MIDI devices.
- `progress-and-delivery`: Local progress and static Pages deployment.

## Impact

A static Vite app, bundled lesson data, Web Audio and Web MIDI browser APIs, browser storage, and a GitHub Actions deployment.
