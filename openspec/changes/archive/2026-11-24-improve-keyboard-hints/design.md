## Context

The on-screen keyboard uses a fixed minimum width. Guided practice supplies its current pitch group directly to the keyboard.

## Goals / Non-Goals

Keep wide two-hand passages playable on narrow phones and make the hint control work consistently. Retain pitch mappings, practice scoring, and beginner key sizes.

## Decisions

- Reduce the minimum keyboard width for two-hand lessons on narrow screens and retain horizontal scrolling when needed.
- Keep hint pitches separate from pressed keys. Use guided pitch groups in guided practice and sounding notes from the selected passage in timed practice and demonstrations.
- Reveal both ends of the hinted interval when it fits. Remember an explicitly chosen hint setting while navigating lessons in the same session.
